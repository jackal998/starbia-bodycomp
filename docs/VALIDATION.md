# 欄位對照是怎麼驗證的

STARBIA 701 的 QR 內容是 base64(gzip(一行 CSV，222 欄))，廠商沒有公開欄位定義。
`scripts/starbia_qr.py` 裡的對照（`FIELDS` / `RANGES` / `SEGMENTS` / `SCORES`）是用**機器螢幕照片**逐項對出來、再驗證的。
這份文件說明方法和結果；作者的原始照片與數值是個人資料，不在這個 repo 裡。

## 方法

1. 同一次量測同時拍 **QR** 和機器螢幕報告的每一頁（報告總覽、體組成分析、各肢段……）。
2. 把螢幕上**每一個看得到的數值**都抄進 `raw/<日期>/screen_values.csv`（照抄，含小數位數）。
3. `scripts/verify_screen.py` 逐項跟 QR 解出的值比對，寫出 `raw/<日期>/VERIFY.md`：

   | 種類 | 比對方式 |
   |---|---|
   | `num` 數字 | 依螢幕的小數位數，差距 ≤ 半個末位 |
   | `text` 文字 | 完全相同 |
   | `bar` 長條／圖上的點 | 螢幕上只有圖形、沒有數字：以軌道外框與刻度校正後量末端位置，容許 ±tol（依量法的實測精度） |

4. 在 QR 裡找吻合的欄位時，要求「三天都吻合，而且是唯一吻合的欄位」才算**確認**。

## 結果

三個不同日期的量測，每次都把螢幕上所有數值抄下來比對：

| | ✅ 一致 | 🟡 圖形量測，在精度內一致 | ⚪ 螢幕有、QR 找不到 | ❌ 不一致 |
|---|---:|---:|---:|---:|
| 第 1 天 | 95 | 12 | 1 | 0 |
| 第 2 天 | 103 | 12 | 1 | 0 |
| 第 3 天 | 106 | 12 | 1 | 0 |

螢幕的「歷史記錄」頁也列出之前每次的體重／肌肉／骨密度，所以沒有螢幕照片的量測也有部分核對到。

### 各部分的可信度

| | 內容 |
|---|---|
| ✅ 確認 | 所有表格數值與正常範圍、各肢段 kg 與評分（5 肢段 × 肌肉／脂肪／骨礦物）、9 個整體評分（脂肪、肌肉、骨礦物、水分、上肢、下肢、軀幹、SMI、ASMI）、骨密度 T-score |
| 🟡 推定 | **相位角評分**：≈ 1.4 ×（相位角取一位小數 − 6.4）；QR 用一位小數的相位角算，螢幕用未進位的值，差最多 ±0.07，報表標「≈」。**內臟脂肪等級** = 面積 ÷ 10，取整規則未知（小數 ≥ .5 時標「?」）。**體脂率與 BMI 的分類分界**：依螢幕刻度量得；女性的分界未經核對。**骨密度圖的同齡參考帶**：依螢幕描繪 |
| ⚪ 未還原 | **骨骼肌評分**：螢幕有長條，QR 裡沒有吻合的欄位（可能是機器顯示時才計算），報表不畫。BMI 各年齡風險曲線、相位角百分位圖、生物阻抗向量圖 |
| ℹ️ 本工具自訂 | 評分的狀態文字與顏色（良好／尚可／注意／警示／風險高，以 0／−1／−2／−2.5 分界）、「與上次比較」的改善／變差判斷、趨勢圖的統計。機器只用漸層色 |

### 欄位關係檢查

這 12 條關係在作者的每一次量測都成立，`consistency_issues()` 每次上傳都會檢查，CI 也會：

體重 = 去脂質量 + 脂肪質量 · 脂肪質量 = 必須脂肪 + 儲存脂肪 · 總體水分 = 細胞內液 + 細胞外液 · 體脂率 = 脂肪 ÷ 體重 ·
BMI = 體重 ÷ 身高² · 基礎代謝率 = 370 + 21.6 × 去脂質量 · 上肢肌肉 = 左右上肢 · 下肢肌肉 = 左右下肢 ·
SMI = 骨骼肌 ÷ 身高² · ASMI = 四肢肌肉 ÷ 身高² · 上肢評分 = 兩臂評分平均 · 下肢評分 = 兩腿評分平均

不成立 → 機器韌體或 QR 格式可能變了，請重新驗證。

### 進位

QR 只有兩位小數。剛好落在進位邊界（例如 x.x5 要顯示一位）時，機器用內部更精確的值決定進位方向
（螢幕上有的進位、有的捨去），無從得知 → 報表多顯示一位，不猜。

## 用你自己的螢幕照片驗證

如果你的機器韌體不同，或想確認：

1. 同一次量測拍 QR 和螢幕各頁，照平常的流程上傳（螢幕照片放在 issue 的「機器螢幕報告照片」欄位）。
2. 在 `body-comp/raw/<日期>/` 新增 `screen_values.csv`，欄位：

   | 欄位 | 內容 |
   |---|---|
   | `measured_at` | 哪一次量測（實際時間，例如 `2026-01-15 18:30`） |
   | `page` / `item` | 螢幕哪一頁、哪一項 |
   | `shown` | 螢幕上顯示的文字（照抄，包含小數位數） |
   | `ref` | 對應的值：`v.<欄位>`、`person.<欄位>`、`range.<指標>.<0\|1>`、`seg.<肢段>.<欄位>`、`score.<評分>`、`d.<推算值>`、`machine_age`、`machine_time`；空白 = QR 裡還沒對出 |
   | `kind` | `num`／`text`／`bar` |
   | `tol` | （選填）`bar` 的容許誤差，預設 0.1 |
   | `note` | （選填）備註 |

3. push 後 `reports.yml` 會跑驗證並寫出 `VERIFY.md`；有任何 ❌ 就會失敗。也可以本機跑 `python scripts/verify_screen.py`。
